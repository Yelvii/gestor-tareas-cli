
# Gestor de Tareas CLI

## Descripcion
Proyecto desarrollado en Python para administrar tareas desde la consola.

## Requisitos previos
- Python 3 instalado.
- Git instalado.

## Uso basico
1. Clonar o descargar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el programa con:

   python app.py

## Funcionalidades
- Agregar tareas.
- Listar tareas.
- Completar tareas.
- Eliminar tareas.
